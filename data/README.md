# 数据集结构与可复现边界

本目录目前只公开**数据模式和状态规则**，不存放教材原文、截图、可还原教材的大段文本、学生数据或未授权的外部标注工作簿。当前候选和人工初标数据如需公开，应先完成逐条筛选、双人复标/仲裁，并确认短引和数据发布权限。

`schema.csv`概列文档、候选、交际事件、活动学习机会、标注、AI输出、刺激和学习者响应的字段。具体项目可按研究对象增删字段，但须预先冻结字段定义和纳排规则。

## 数据状态语义

- **候选**：机器检索命中，尚未做语言学判断；不计作有效事件。
- **研究者初标**：研究者核过原页的工作标签；不是金标准。
- **双人仲裁金标准**：须有两位实际独立编码者及可审计仲裁记录。
- **未运行/未采集/不适用/不可判定/未作答**：含义不同，不可互换或替换成0。
- **教材呈现**：正文、语法栏目、练习和附录听力稿可能重复同一话语；通过TextGroupID、EventGroupID、ConversationGroupID关联。

## 尚未发布的数据

工作目录中有一个局部试点工作簿，含教材短引和相关页截图。本仓库目前不包含该工作簿、截图或教材文件。公开教材目录链接仅用于来源发现；如研究者准备共享事件级原文数据，应先进行版权、平台条款、最小必要引用和再分发审查。
