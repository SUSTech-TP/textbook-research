# Chinese English Textbook Research

本仓库用于整理中国中小学英语教材的可审计语法—语用研究资源。本轮试点聚焦 **Could you / Could I、请求与许可**，采用“形式—功能—语境—教材学习机会”框架。

## 从这里开始

- 教材书目与获取入口：[sources/english-textbooks/README.md](sources/english-textbooks/README.md)
- 可追溯来源清单：[sources/english-textbooks/manifest.csv](sources/english-textbooks/manifest.csv)
- 数据集结构和状态约定：[data/README.md](data/README.md)
- 字段模式：[data/schema.csv](data/schema.csv)
- 当前处理范围与限制：[study/processing-status.md](study/processing-status.md)

## 版权与内容边界

本仓库**不存放**受版权保护的教材PDF、整页截图、长段落原文或第三方用户上传工作簿。`manifest.csv`所列部分入口是第三方公开镜像，**公开可访问不代表开放许可**；链接仅帮助研究者定位书目和核查来源。请先确认使用、保存、引用和再分发条件。

本仓库当前只登记书目链接、版本/取得核验状态、字段模式和处理方法。教材原件和含原文/截图的本地试点表保留在研究者受控工作目录；未获得许可前不推送。

## 研究状态

目前是局部教材页的探索性试点，不是全国版本普查或完整标注语料；文本搜索命中不是有效事件频数。人工初标尚未由第二位编码者复核或仲裁。尚无AI运行、学生实验或学习效果数据。参见 [study/processing-status.md](study/processing-status.md)。
