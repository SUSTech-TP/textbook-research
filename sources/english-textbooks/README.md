# 中小学英语教材来源入口

本页记录本轮已在本地试读的四册人教旧版英语教材的书目发现入口。所列GitHub文件属于第三方公开镜像；其仓库没有可据以认定教材开放许可的license声明。**请将其视为来源定位链接，不要据此认定教材为开源材料或获得复制、上传、OCR再发布许可。**

## 可用入口

详见[机器可读来源清单](manifest.csv)。目前包含：

- 人教Go for it八年级上册、下册和九年级全一册的第三方镜像文件链接；
- 人教PEP（三年级起点）六年级上册的第三方镜像文件链接；
- 人教社八年级英语配套资源官方栏目链接（仅供对应资源/版本核对，不等同教材全文下载）。

## 版本和访问注意事项

1. 本地PDF的版权页、封面、版次、印次并不完整一致；逐册核对，避免根据仓库文件名推断版次。
2. 八年级下册本地样本是扫描图像版，文本层不可直接检索；本轮只人工核了局部页。八年级上册、九年级和PEP六上文本层能检索，但候选仍须逐页人工筛查。
3. 页面可下载/打开，只能说明技术可访问，不能说明可公开存储或再分发。
4. 若后续取得出版社或权利方的书面许可，请另建授权记录，并确认允许的版本、范围、用途、存储期限和公开方式后再考虑加入二进制教材文件。
